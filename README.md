# simple-browser

Electron/Chromium 기반의 가벼운 데스크톱 브라우저입니다. 설치 버전은 Node.js나 터미널 없이 실행됩니다.

## 설치 파일

- Apple Silicon Mac 설치 DMG: `dist/simple-browser-0.1.5-mac-arm64.dmg` — 열어서 `simple-browser.app`을 `Applications`로 드래그합니다.

- Windows 64비트: `dist/simple-browser-0.1.5-win-x64.exe`

Mac 빌드는 로컬 테스트용 ad-hoc 서명을 사용하며 Apple 공증은 포함하지 않습니다. Windows 빌드는 배포 인증서 서명을 포함하지 않습니다. 정식 외부 배포 시 인증서와 공증 설정을 추가해야 합니다.

## 기능

- 여러 탭, 새 탭 자동 표시, 탭 좌우 버튼·휠·트랙패드 스크롤
- Google 기본 검색, 주소 입력, 뒤로·앞으로·새로고침
- 북마크와 북마크 바
- `↓` 버튼은 독립된 다운로드 화면을 엽니다. 톱니바퀴는 홈페이지·광고 제거·암호 설정만 표시합니다.
- 오른쪽 톱니바퀴 또는 macOS `⌘,`로 설정 열기
- 홈페이지 주소 설정: 홈 버튼으로 이동, 빈 주소는 새 탭 화면
- 광고 제거 켜기/끄기: 네이버의 `{검색어} 관련 광고` 카드, 메인 검색창 오른쪽 작은 광고 배너·상단 배너·카테고리픽/지금뜨는/쇼핑라이브 상품 카드·추천/카테크/웹툰 등의 추천 피드·오른쪽 광고·추천 아이템 광고·하단 세 광고 카드와 알려진 광고 서버 차단. 광고 소재가 바뀌어도 광고 슬롯을 기준으로 숨기고, 해제하면 복원합니다. 모든 사이트의 모든 광고를 제거하는 필터 목록은 아닙니다.
- 이미지 우클릭 → 이미지 다른 이름으로 저장, 링크 다른 이름으로 저장
- 로그인 팝업·POST·Blob 다운로드, 저장 위치 선택, 진행·완료·중단 상태 및 폴더에서 보기
- HTTPS 로그인 버튼·Enter·양식 제출 시 암호 저장 확인. 같은 출처의 저장 계정이 하나면 재방문 시 빈 로그인 입력란에 자동 채우기, 여러 개면 열쇠 버튼으로 선택, 설정에서 삭제
- 암호는 Electron safeStorage를 통해 macOS Keychain·Windows DPAPI 기반으로 암호화하여 로컬 저장합니다. 저장소를 사용할 수 없으면 평문 저장으로 대체하지 않습니다. 로그인 성공 여부를 자동 판별하지 않으며, 표준 로그인 양식과 네이버처럼 버튼에서 암호화 후 직접 제출하는 흐름을 지원합니다.
- 페이지와 브라우저 UI 사이의 컨텍스트 격리, 웹사이트 Node.js 비활성화
- 현재 탭에 개발자 도구 도킹 (`⌘⌥I` / `Ctrl+Shift+I` / `F12`)

광고 제거를 해제한 뒤 차단된 네트워크 리소스를 다시 받으려면 페이지를 새로고침하세요. 다운로드 목록은 이번 앱 실행 동안만 유지되며, 저장 파일은 종료해도 남습니다. 암호 저장 기능은 비밀번호 동기화·생성·외부 관리 도구 가져오기를 포함하지 않습니다.

## 소스로 실행·빌드

빌드 컴퓨터에는 Node.js 22 이상이 필요합니다.

```bash
npm ci
npm start
npm run check
npm test
npm run test:smoke
```

```bash
npm run dist:mac        # Apple Silicon 앱·DMG (macOS에서 실행)
npm run dist:mac:intel  # Intel Mac 앱·DMG (macOS에서 실행)
npm run dist:win        # Windows x64 NSIS 설치 파일
npm run dist:mac:dmg    # 선택: macOS DMG 생성
```

`npm run pack:mac`은 앱 번들만 생성합니다. Mac DMG는 HFS+ 이미지를 직접 생성한 다음 압축해 만듭니다. 이미지 생성 과정에서 추가되는 Finder 메타데이터를 정리한 뒤 앱 서명과 이미지 체크섬을 검증합니다. ZIP 파일과 중간 ZIP은 생성하지 않습니다. Windows는 차등 업데이트 패키지를 비활성화해 blockmap 파일도 생성하지 않습니다. 배포 파일은 DMG와 EXE만 제공합니다. Windows 빌드는 Windows에서 실행하거나 electron-builder가 지원하는 교차 빌드 환경에서 실행합니다.

실행 스크립트는 개발 도구가 설정한 `ELECTRON_RUN_AS_NODE`를 제거하므로 Electron이 Node 모드로 잘못 시작되는 문제를 방지합니다. 개발 실행은 Electron 실행 파일을 사용하지만 설치 후에는 `simple-browser.app` / `simple-browser.exe`를 사용합니다.

## 로컬에서 테스트하기

### 1. 최신 소스로 실행

Node.js 22 이상을 설치한 뒤, 터미널에서 소스 폴더로 이동합니다. 현재 Mac 작업 폴더에서는 다음 명령을 실행하세요.

```bash
cd "프로젝트 설치 디렉토리"
npm ci
npm start
```

소스 폴더를 다른 위치에 복사했다면 해당 폴더에서 같은 명령을 실행합니다. Windows도 소스 폴더에서 PowerShell 또는 명령 프롬프트로 `npm ci`, `npm start`를 실행하면 됩니다. 의존성과 Electron 실행 파일을 처음 다운로드할 때는 인터넷 연결이 필요합니다.

코드를 수정한 뒤에는 실행 중인 앱을 완전히 종료하고 `npm start`를 다시 실행하세요. 로그를 보면서 실행하려면 `npm run dev`를 사용합니다.

### 2. 자동 테스트

```bash
npm run check       # JavaScript 문법 검사
npm test            # 검색·설정·광고 제거·암호 저장 단위 테스트
npm run test:smoke  # 실제 앱 창에서 통합 테스트 후 자동 종료
```

`test:smoke`는 별도 테스트 프로필 `work/smoke-profile/`을 사용합니다. 로컬 테스트 서버를 띄워 다운로드를 확인하고, 파일도 이 테스트 프로필에 저장합니다. 일반 실행에서 저장한 북마크·설정·암호를 테스트에 사용하지 않습니다. 통합 테스트 중 창이 열리고 닫히는 것은 정상입니다. 성공하면 터미널에 `SMOKE PASS`가 표시됩니다. 설정 화면 캡처는 `outputs/settings.png`에서 확인할 수 있습니다.

### 3. 직접 확인할 항목

| 기능 | 확인 방법 | 정상 동작 |
| --- | --- | --- |
| 이름·아이콘 | 앱을 열고 Dock/작업표시줄·메뉴 확인 | `simple-browser`와 여우 아이콘 표시. 설치 버전 확인은 아래 4번 사용 |
| Google 검색 | 주소창에 `책상` 입력 후 Enter | Google 검색 결과로 이동 |
| 설정에서 주소 이동 | 설정 또는 다운로드 화면에서 주소창에 주소 입력 후 Enter | 열린 화면을 닫고 현재 탭에서 바로 이동 |
| 홈페이지 | 톱니바퀴 → 홈페이지에 `https://www.google.com` 입력 → 저장 → 홈 버튼 | 지정한 사이트로 이동. 앱 재실행 후 설정 유지 |
| 광고 제거 | 네이버에서 `책상` 검색 → 설정에서 광고 제거 켜기 | `책상 관련 광고` 카드 숨김. 일반 결과는 유지 |
| 메인 광고 제거 | 네이버 메인에서 광고 제거 켜기 | 상단 배너·오른쪽 광고/아이템·하단 광고 묶음 숨김, 뉴스·로그인·날씨·일반 링크 유지 |
| 광고 복원 | 광고 제거 끄기 → 필요하면 페이지 새로고침 | 숨겼던 카드 복원 |
| 탭 이동 | `+`를 15번 정도 눌러 새 탭 생성 | `+`가 항상 보이고 활성 탭이 화면에 표시 |
| 탭 스크롤 | 탭 위에서 마우스 휠·트랙패드 또는 좌우 버튼 사용 | 탭 목록을 좌우로 이동. 창 폭을 줄여도 활성 탭 표시 |
| 개발자 도구 | Mac `⌘⌥I`, Windows `Ctrl+Shift+I` 또는 `F12` | 현재 페이지 옆에 도킹되고 페이지를 덮지 않음 |
| 이미지 저장 | 이미지 위에서 우클릭 → 이미지 다른 이름으로 저장 | 저장 위치 선택창 표시, 저장 후 `↓`에서 완료 확인 |
| 로그인 후 다운로드 | 사내 사이트 로그인 후 다운로드 동작 실행 | 저장창 또는 다운로드 진행 상태 표시. `↓`에서 완료·중단 상태 확인 |
| 파일 찾기 | `↓` → 완료된 파일의 폴더에서 보기 | Finder/탐색기에서 실제 저장 파일 선택 |
| 암호 저장 | HTTPS 사이트의 일반 로그인 양식에 테스트 계정 입력 후 로그인 → 저장 선택 | 암호 저장 확인창 표시 |
| 암호 채우기 | 저장 후 로그아웃하고 같은 사이트의 로그인 페이지로 돌아오기 | 저장 계정이 하나면 빈 입력란에 자동 입력. 여러 개면 `🔑`에서 선택. 이미 입력 중인 값은 유지하고 자동 제출하지 않음 |
| 암호 삭제 | 설정 → 저장된 암호 → 삭제 | 목록에서 제거되고 앱 재실행 후에도 삭제 유지 |

암호 저장은 `https://` 로그인과 표준 비밀번호 양식을 대상으로 합니다. 가입·비밀번호 변경 양식이나 사이트 자체의 특수 로그인은 자동 감지되지 않을 수 있습니다. 사내 서버의 실제 로그인 흐름은 이 환경에서 접속해 검증하지 못했으므로 해당 서버에서 직접 확인해야 합니다. 자동 테스트에는 새 창 링크·noopener 팝업, 네이버 방식의 로그인 버튼 입력값 감지, 로그인 팝업 POST 다운로드와 Blob 파일 다운로드가 포함됩니다. 실제 네이버 계정으로 로그인하는 테스트는 수행하지 않습니다.

### 4. Node.js 없이 설치 버전 확인

Mac에서는 `dist/simple-browser-0.1.5-mac-arm64.dmg`를 열고 `simple-browser.app`을 `Applications`로 드래그합니다. 복사가 끝나면 이미지를 추출하고 응용 프로그램 폴더에서 실행합니다. Apple Silicon Mac용입니다. Windows에서는 `dist/simple-browser-0.1.5-win-x64.exe`를 실행해 설치합니다. 이미 이전 버전이 실행 중이면 완전히 종료한 뒤 새 버전을 실행하세요.

소스 변경을 설치 버전에 반영하려면 Mac에서 `npm run dist:mac`, Windows용은 `npm run dist:win`으로 다시 빌드합니다. `npm start`는 개발 실행이므로 운영체제 일부 화면에서 기반 실행 파일인 Electron 이름이 남을 수 있습니다. 최종 앱 이름 확인은 설치 버전으로 진행합니다.

## 검증 범위

단위 테스트는 Google 검색, 홈페이지 URL 검증, 광고 도메인 경계, 검색어별 광고 카드·동적 카드 숨김과 복원, 암호화 저장·출처 분리·삭제를 확인합니다. Electron 통합 테스트는 탭·개발자 도구·설정 화면, 일반 다운로드·로그인 팝업 POST·Blob 다운로드, 다중 탭 자동 표시와 휠 이동을 확인합니다. 사내 서버의 실제 로그인과 Windows에서의 실행은 해당 환경에서 별도 확인이 필요합니다.

카메라·마이크·위치 등의 사이트 권한은 현재 거부합니다. Chrome 계정 동기화, 확장 프로그램 스토어, 자동 업데이트는 포함하지 않습니다. 프로젝트 라이선스는 MIT이며 Electron/Chromium의 라이선스 파일은 설치 패키지에 포함됩니다.
